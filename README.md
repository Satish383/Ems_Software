# EmployeeHub — Employee Management System (EMS)

A premium, fully responsive, **frontend-only** HR dashboard built with React + Vite + Tailwind CSS.
Includes a demo authentication flow, dashboard analytics, employee directory, attendance, leave
management, payroll, performance, reports, notifications, and settings.

> ⚠️ **Demo project.** All data is fictional, stored in the browser (localStorage), and no real
> backend, database, or payment processing is involved. Clearly labeled "demo" throughout the UI.

---

## ✨ Features

- **Demo authentication** with mock users (no real security)
- **Collapsible sidebar** (desktop) + mobile drawer
- **Top navbar** with breadcrumbs, quick search, notifications, theme toggle
- **Dark / light theme** persisted to localStorage
- **Dashboard** with Recharts analytics (growth, attendance, department pie, activities)
- **Employee directory** — search, filters, sorting, pagination, table/grid views, bulk actions, CSV export
- **Add / edit employees** with React Hook Form validation and photo preview
- **Employee details** with tabs (Overview, Attendance, Leave, Salary, Documents)
- **Departments & Designations** CRUD-style modals
- **Attendance** — daily list + monthly calendar, check-in/out, manual entry
- **Leave management** — tabs, approve/reject, rejection reason, apply modal, balances
- **Payroll** — month selector, payslip modal, print, CSV export
- **Performance** — rating distribution chart, reviews table, feedback & goals modals
- **Reports** — multiple chart categories with date & department filters
- **Notifications** — read/unread, mark all, filters
- **Settings** — profile, company, appearance, notifications, work schedule, leave types, reset demo
- **My Profile** with password-change modal
- **404 page** for unknown routes
- **Toast notifications**, confirmation dialogs, empty/loading/error states
- Fully responsive at **375px, 768px, 1024px, 1440px**
